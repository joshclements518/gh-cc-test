# PRD — Friday Snack Vote

**Epic**: #101  
**Status**: Implemented

## Overview

Create a simple poll application for Friday snack voting. Users can create polls, vote via share links, and see results in real-time.

## Scope

Keep scope tiny:
- Create polls with a question and multiple options
- Vote via shareable link
- View results immediately after voting
- No authentication required
- No user accounts

## User Stories

1. **Create poll**: As a poll creator, I want to create a poll with a question and multiple options, so that I can share it with others to vote.

2. **Cast vote**: As a voter, I want to click a shareable link, select an option, and submit my vote, so that I can participate in the poll.

3. **View results**: As a voter, I want to see the poll results after voting, so that I know what others chose.

## Success Criteria

- Poll creation takes less than 30 seconds
- Shareable links work on mobile devices
- Results display immediately after voting
- Mobile-first design works on common screen sizes

## Out of Scope

- User authentication
- Poll editing or deletion
- Vote modification
- Poll expiration
- Advanced analytics
