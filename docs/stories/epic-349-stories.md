## 1. Add Explore Wellness Chip
Implement the Explore Wellness chip that filters MockCatalog.venues for Spa OR Fitness.

### Acceptance criteria
- The Wellness chip is displayed alongside existing category chips.
- Selecting the Wellness chip filters the displayed venues to only those categorized as Spa or Fitness.
- If no venues match the criteria, a message indicating "No results found" is displayed.
